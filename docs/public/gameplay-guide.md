# Gameplay Guide (Public Skeleton)

> Status: scaffolding document. Gameplay values and many rules are intentionally omitted or provisional.

## What this game is
- Browser RTS with persistent player state.
- Map-centric play: exploration, expansion, force positioning, and conflict.
- Tick-based backend simulation.

## Core loop (high level)
1. Establish and develop bases.
2. Produce and position forces.
3. Contest map control and strategic locations.
4. Adapt to map/resource/combat outcomes over time.

## Important note
Detailed formulas and internal balancing are maintained in internal docs and may change frequently.
